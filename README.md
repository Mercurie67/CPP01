# CPP Module 01

## 📚 Description

This project introduces deeper aspects of **C++ programming (C++98 standard)**, focusing on memory management, references, pointers, dynamic allocation, and the first real use of object lifetime control.

The exercises reinforce how C++ differs from C, especially in:
- Dynamic memory allocation (`new` / `delete`)
- References vs pointers
- Object lifecycle
- Memory ownership and leaks
- Encapsulation and class design

## 🧠 Key Concepts

- Heap vs Stack allocation
- `new` and `delete`
- References (`&`)
- Pointers and pointer-to-member usage
- Object lifetime management
- Deep vs shallow copy
- Basic class composition
- File I/O using `<fstream>`
